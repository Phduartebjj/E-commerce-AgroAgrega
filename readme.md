#  AgroAgrega

> Plataforma voltada para integrar e conectar soluções do setor agronegócio, facilitando o acesso a serviços, gestão de dados e conexão entre produtores e parceiros.

---

##  Sobre o Projeto

O **AgroAgrega** foi concebido como um trabalho acadêmico com o objetivo de aproximar a tecnologia do agronegócio. A plataforma atua unificando informações e serviços essenciais para pequenos e médios produtores rurais, otimizando fluxos de trabalho e promovendo a eficiência no campo.

---

##  Funcionalidades Principais

- **Painel de Controle:** Visualização simplificada de métricas e dados de produção.
- **Conexão de Parceiros:** Espaço para integração entre fornecedores, compradores e produtores.
- **Gestão Simplificada:** Cadastro de insumos, colheitas e relatórios operacionais.

---

## Como Executar o Projeto

### Pré-requisitos
Antes de começar, certifique-se de possuir as seguintes ferramentas instaladas:
- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/)

### Instalação

1. Clone o repositório:
   ```bash
   git clone
   ```

2. Entre no diretório raiz do repositório:
   ```bash
   cd E-commerce-AgroAgrega
   ```

3. Instale as dependências:
   ```bash
   npm --prefix e-commerce-AgroAgrega install
   ```

4. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```

   O script da raiz encaminha o comando para o projeto Angular em
   `e-commerce-AgroAgrega`. O servidor estará disponível em `http://localhost:4200/`.
